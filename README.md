# Tashkent City Mall — школьный проект

Готовый статический сайт на английском и русском языках.

## Открытие

Дважды нажмите на `index.html`. Фотографии, шрифты и библиотека 3D сохранены локально: для основного сайта интернет не нужен. Внешние ссылки на источники и карту требуют подключения.

Дополнительный вариант для разработки: `npm.cmd start` на Windows или `npm start` на других системах. Node.js нужен только для этого варианта. Устанавливать зависимости не требуется.

## Возможности

- Английский по умолчанию; кнопки EN / RU переводят основной контент, подписи, альтернативный текст фотографий и названия элементов управления.
- Адаптивная вёрстка, мобильная навигация, анимации с учётом настройки уменьшенного движения.
- Фильтры магазинов, увеличиваемая галерея с клавиатурной навигацией.
- Собственная интерактивная 3D-сцена: вращение перетаскиванием, кнопки масштаба, автовращение и сброс. При фокусе на сцене доступны стрелки, плюс, минус и 0.
- При отсутствии WebGL показывается реальное фото комплекса.

## Содержание и источники

Источники проверены 12 сентября 2026 года и перечислены в раскрываемом разделе внизу сайта. Фотографии взяты из публикаций Tashkent City Mall, Afisha.uz, Kursiv Media и SARDA Group; ссылки сохранены на сайте. Каталог является подборкой, ассортимент и расписание могут изменяться.

3D-сцена — авторская иллюстративная реконструкция по внешним фотографиям: фасад, купол, башни и окружение. Геометрия и расстояния упрощены; это не точная инженерная копия и не навигационная карта.

Тексты «My Opinion» и пример дня выражают позицию школьного проекта, не утверждая, что автор посещал каждое заведение.

## Файлы

- `index.html` — точка входа.
- `style.css`, `fonts.css` — оформление и локальные шрифты.
- `app.js` — контент, перевод и интерфейс.
- `scene.js` — архитектурная модель и её управление.
- `assets/` — фотографии, шрифты и Three.js r170 (MIT).
- `server.cjs` — необязательный локальный сервер.
